# 期中作業：AI 客服信件分類系統

### 1. 做了什麼
開發一個 Python 程式，能自動讀取客訴信件，並判斷該信件屬於「退貨」、「報修」或「抱怨」。

### 2. 怎麼執行
在終端機使用 uv 工具安裝套件後，輸入指令 `python main.py` 即可執行。

### 3. 執行結果
程式成功將測試信件（吹風機壞掉）分類為「退貨」，並順利印出 AI 的信心水準。

### 4. AI 使用說明
使用了 OpenAI 的 `gpt-4o-mini` 模型。為了確保 AI 不會亂回答，使用了 Pydantic 進行「結構化輸出」，強制 AI 只能回傳規定的分類標籤與信心水準。
